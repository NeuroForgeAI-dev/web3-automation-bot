> AI-powered Telegram & Discord bot for business automation — customer support, lead generation, bookings, and FAQ.

## 🚀 Features

- **Telegram Bot**: /start, /help, /book, /faq, /contact commands
- **Discord Bot**: Slash commands for all features
- **AI Chat**: GPT integration for intelligent FAQ responses
- **Booking System**: Appointment scheduling with SQLite
- **Lead Capture**: Collect and store business leads
- **Admin Dashboard**: Analytics endpoint for monitoring
- **Multi-language**: English, Russian, Spanish support

## ⚡ Quick Start

```bash
git clone https://github.com/NeuroForgeAI-dev/web3-automation-bot.git
cd web3-automation-bot
cp .env.example .env
pip install -r requirements.txt
python bot.py
```
